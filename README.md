## 功能特性

### 核心功能
- 🎯 **高精度录制** - 采用 `time.perf_counter()` 实现微秒级时间精度
- 🖱️ **全键位捕获** - 左右/中键、侧键、双击、三种拖拽、滚轮、按键释放全覆盖（详见下方动作清单）
- ⌨️ **组合键可靠** - 按物理键码去重，Ctrl+C / Alt+F4 等组合可完整录制与还原
- ⌨️ **全局热键** - F7-F12 后台全局生效，无需激活窗口
- 🔄 **循环回放** - 单次 / 无限循环 / 指定次数
- ⏸️ **暂停恢复** - 随时暂停和恢复回放
- 🛡️ **脚本自检** - 加载与回放前自动体检，坏动作提前标出；单步失败只跳过该步，不再整段中断
- 🔒 **脚本加密** - Base64 + XOR 加密存储，防止数据泄露
- 📂 **脚本管理** - 保存、加载、重命名、删除、自检

### 界面特性
- 🪟 **自动隐藏** - 录制/回放时自动隐藏窗口
- 💡 **状态指示** - 红/绿/灰三色状态指示灯
- 📊 **实时统计** - 录制时长、操作步数、回放进度
- 🎨 **简洁界面** - 轻量级中文 GUI，无多余功能

## 快速开始

### 方式一：直接运行 EXE（推荐）

从 [Releases](https://github.com/yangxivi/shuxiaoxia/releases) 页面下载最新版本的 `shuxiaoxia.exe`（约 17MB），双击直接运行，无需安装 Python 环境。

### 方式二：源码运行

```bash
# 1. 克隆仓库
git clone https://github.com/yangxivi/shuxiaoxia.git
cd shuxiaoxia

# 2. 安装依赖
pip install pyautogui pynput

# 3. 运行程序
python mouse_recorder_pro.py
```

### 方式三：手动打包

```bash
pip install pyautogui pynput pyinstaller
pyinstaller --noconfirm --clean 鼠小侠.spec
```

> 提示：打包用的 Python 需自带 tkinter（Windows 官方安装包默认包含）。

## 使用教程

### 1. 录制操作

```
按 F7 → 倒计时3秒 → 执行操作 → 按 F8 结束
```

1. 按下 **F7** 或点击"开始录制"按钮
2. 等待 3 秒倒计时（防误触）
3. 执行需要录制的鼠标和键盘操作
4. 按下 **F8** 或点击"停止录制"按钮结束录制

### 2. 保存脚本

```
按 F9 → 输入文件名 → 确认保存
```

录制完成后，按 **F9** 保存脚本到 `scripts/` 目录（加密格式 `.mrs`）。

### 3. 加载脚本

点击脚本列表下拉菜单选择脚本，或点击「加载」从外部目录选择。启动时会自动加载最近修改的脚本。

### 4. 回放操作

```
按 F10 开始 → 按 F11 暂停/恢复 → 按 F12 停止
```

1. 加载脚本或确保当前有录制内容
2. 设置循环模式（单次/无限循环/次数）
3. 按下 **F10** 开始回放
4. 按 **F11** 暂停/恢复
5. 按 **F12** 停止回放

## 支持录制的动作类型

### 🖱️ 鼠标动作

| 动作 | 内部标识 | 说明 |
|------|----------|------|
| 移动 / 悬停 | `move` | 记录鼠标坐标变化（不按任何按键） |
| 左键单击 | `left_click` | — |
| 左键双击 | `left_double` | 两次按下间隔 < 350ms 且位置接近 |
| 右键单击 | `right_click` | — |
| 右键双击 | `right_double` | — |
| 中键单击 | `middle_click` | 等同"滚轮按下"，常用于打开新标签页 |
| 中键双击 | `middle_double` | — |
| 侧键 1 单击 | `x1_click` | 通常映射为浏览器「后退」 |
| 侧键 2 单击 | `x2_click` | 通常映射为浏览器「前进」 |
| 左键拖动 | `left_drag` | 移动文件、框选选区、拖动窗口 |
| 右键拖动 | `right_drag` | 右键按住拖动 |
| 中键拖动 | `middle_drag` | 多数软件中为**平移视图** |
| 按键释放 | `mouse_release` | 「按住不点」后的抬起，以及拖拽结束的释放 |
| 滚轮滚动 | `scroll` | 垂直/水平，方向与距离 **1:1 精确匹配** |

**拖拽识别原理**：按下时只记录按键状态，抬起时再判定 —— 抬起前**发生过移动**即判定为拖拽（并追加一条释放动作，让回放正确松开按键）；**未发生移动**则判定为单击/双击。这样既不会漏掉"按住不动再松开"，也能保证框选动作在回放时按键连续不中断。

> ℹ️ 内部另有一个 `keyframe`（关键帧标记）动作类型，预留用于脚本分段定位。当前版本尚未把它绑定到快捷键，因此录制时不会产生该动作。

### ⌨️ 键盘动作

| 类别 | 支持内容 |
|------|----------|
| **普通按键** | 字母 A-Z、数字 0-9、各类符号与中文输入字符 |
| **修饰键** | Shift / Ctrl / Alt / Win，**左右侧分别记录**（如 `ctrl_l`、`ctrl_r`） |
| **功能键** | F1 - F12 |
| **控制键** | Enter、Tab、Backspace、Delete、Insert、Home、End、PageUp、PageDown、方向键、Esc、CapsLock、NumLock、ScrollLock |
| **系统键** | PrintScreen、Pause、Menu（开始键） |
| **组合键** | 任意多键组合，如 Ctrl+C、Alt+F4、Ctrl+Shift+Esc、Win+Shift+S |
| **长按 / 按住** | 按下与释放之间的时长完整保留（Shift、Ctrl、方向键连续移动等） |
| **连击** | 同一键的多次「按下-释放」序列逐次记录 |

**实现要点**：按键去重使用**物理键码（VK）**而非字符编码。因为按住 Ctrl 时字母键的字符会变为空值，若按字符去重会导致按键"卡住"、后续组合键丢失——这正是 `Ctrl+C` / `Ctrl+V` 在旧版本录不进来的根因，V4.0 已修复。

### 🔗 修饰键组合（自动支持，无需配置）

以下组合**不需要任何额外设置**，因为修饰键本身会作为独立按键事件被记录，回放时天然处于按住状态：

| 组合 | 常见用途 |
|------|----------|
| `Ctrl` + 左键 | 打开超链接、点选多个不连续项 |
| `Shift` + 左键 | 范围连续选择 |
| `Alt` + 左键 | 窗口操作、菜单栏 |
| `Ctrl` + 滚轮 | 页面/图片缩放 |
| `Shift` + 滚轮 | 横向滚动 |

### ⚠️ 不会录入脚本的按键

| 按键 | 原因 |
|------|------|
| `F7` `F8` `F9` `F10` `F11` `F12` | 软件自身的全局快捷键 |
| `Esc` | 保留 |
| `空格` | 保留（预留给关键帧标记功能） |

> 录制开始后的前 500ms 内的操作会被忽略，用于防止误触。

## 脚本自检

脚本在**加载时**与**回放前**都会自动体检，也可随时点击「自检」按钮手动触发：

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 空脚本 | 错误 | 没有任何可回放的动作 |
| 不支持的动作类型 | 警告 | 回放时会被静默跳过 |
| 键盘动作无法识别 | 警告 | 缺少按键信息，回放时该步被跳过 |
| 坐标超出屏幕范围 | 警告 | 回放时自动裁剪到屏幕边缘 |
| 孤立的按键释放 | 警告 | 此前没有对应的按下或拖拽 |
| 结尾按键仍处拖拽 | 警告 | 末尾缺少释放动作 |

自检结果会写入运行日志，并标注具体步数（如"第 128 步：…"）。**回放容错**：个别动作执行失败会被跳过并计入日志，不会再导致整个回放中断。

## 注意事项

1. **屏幕分辨率**：录制和回放时请确保屏幕分辨率一致
2. **回放速度**：固定为 1 倍速，与录制时长一致
3. **紧急停止**：将鼠标快速移到屏幕左上角可紧急停止（FAILSAFE 机制）
4. **脚本格式**：`.mrs` 文件为加密格式，不可直接编辑
5. **单实例运行**：只允许一个程序实例运行
6. **旧版兼容**：旧版本录制的 `.mrs` 脚本可正常加载回放

## 常见问题

### Q1: 录制的动作回放时位置不对？
确保录制和回放时屏幕分辨率一致，目标窗口位置相同。

### Q2: 快捷键不生效？
检查是否有其他软件占用了 F7-F12 快捷键。

### Q3: 脚本保存后找不到？
脚本默认保存在程序目录下的 `scripts/` 文件夹中。

### Q4: 回放中途停止了，日志提示"执行动作失败"？
V4.0 起单条动作失败只会跳过该步并继续回放。请查看运行日志中"N 个动作执行失败已跳过"的提示，并用「自检」按钮定位问题步骤。

### Q5: 回放时速度与录制不一致？
软件采用绝对时间锚点控制回放节奏，如仍有差异请检查是否有其他程序占用系统资源。

### Q6: 如何发布新版本？
```bash
set GITHUB_TOKEN=你的token
python 发布_v4.py
```
脚本会自动完成：校验令牌 → 同步源码与官网 → 推送 main → 创建 tag → 创建/更新 Release 并上传产物 → 回读校验。
