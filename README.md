## 功能特性

### 核心功能
- 🎯 **高精度录制** - 采用 `time.perf_counter()` 实现微秒级时间精度
- 🖱️ **全动作捕获** - 支持鼠标移动、点击、双击、拖动、滚轮、键盘按键录制
- ⌨️ **全局热键** - F7-F12 后台全局生效，无需激活窗口
- 🔄 **循环回放** - 单次 / 无限循环 / 指定次数
- ⏸️ **暂停恢复** - 随时暂停和恢复回放
- 🔒 **脚本加密** - Base64 + XOR 加密存储，防止数据泄露
- 📂 **脚本管理** - 保存、加载、重命名、删除脚本

### 界面特性
- 🪟 **自动隐藏** - 录制/回放时自动隐藏窗口
- 💡 **状态指示** - 红/绿/灰三色状态指示灯
- 📊 **实时统计** - 录制时长、操作步数、回放进度
- 🎨 **简洁界面** - 轻量级中文 GUI，无多余功能

## 快速开始

### 方式一：直接运行 EXE（推荐）

从 [Releases](https://github.com/yangxivi/shuxiaoxia/releases) 页面下载最新版本的 `鼠小侠.exe`，双击直接运行，无需安装 Python 环境。

### 方式二：源码运行

```bash
# 1. 克隆仓库
git clone https://github.com/yangxivi/shuxiaoxia.git
cd shuxiaoxia

# 2. 安装依赖
pip install pyautogui pynput

# 3. 运行程序
python mouse_recorder_pro.py
```

### 方式三：手动打包

```bash
# 安装打包工具
pip install pyautogui pynput pyinstaller

# 打包为单文件 EXE
pyinstaller --noconfirm --clean --onefile --windowed --name "鼠小侠" mouse_recorder_pro.py
```

## 快捷键说明

| 快捷键 | 功能 | 触发条件 |
|--------|------|----------|
| **F7** | 开始录制 | 待机状态 |
| **F8** | 停止录制 | 录制状态 |
| **F9** | 保存脚本 | 待机状态 |
| **F10** | 开始回放 | 待机状态（脚本不为空） |
| **F11** | 暂停/恢复回放 | 回放状态 |
| **F12** | 停止回放 | 回放/暂停状态 |

> 💡 快捷键在后台全局生效，无需激活软件窗口。

## 使用教程

### 1. 录制操作

```
按 F7 → 倒计时3秒 → 执行操作 → 按 F8 结束
```

1. 按下 **F7** 或点击"开始录制"按钮
2. 等待 3 秒倒计时（防误触）
3. 执行需要录制的鼠标和键盘操作
4. 按下 **F8** 或点击"停止录制"按钮结束录制

### 2. 保存脚本

```
按 F9 → 输入文件名 → 确认保存
```

录制完成后，按 **F9** 保存脚本到 `scripts/` 目录（加密格式 `.mrs`）。

### 3. 加载脚本

点击脚本列表下拉菜单，选择要加载的脚本文件即可。

### 4. 回放操作

```
按 F10 开始 → 按 F11 暂停/恢复 → 按 F12 停止
```

1. 加载脚本或确保当前有录制内容
2. 设置循环模式（单次/无限循环/次数）
3. 按下 **F10** 开始回放
4. 按 **F11** 暂停/恢复
5. 按 **F12** 停止回放

## 循环模式

| 模式 | 说明 |
|------|------|
| **单次** | 回放一次后自动停止（默认） |
| **无限循环** | 持续循环回放，直到手动停止 |
| **次数** | 按指定次数循环回放 |

## 支持的动作类型

| 动作类型 | 说明 |
|----------|------|
| 鼠标移动 | 记录鼠标坐标变化 |
| 左键单击 | 记录左键点击 |

## 注意事项

1. **屏幕分辨率**：录制和回放时请确保屏幕分辨率一致
2. **回放速度**：固定为 1 倍速，与录制时长一致
3. **紧急停止**：将鼠标快速移到屏幕左上角可紧急停止（FAILSAFE 机制）
4. **脚本格式**：`.mrs` 文件为加密格式，不可直接编辑
5. **单实例运行**：只允许一个程序实例运行

## 常见问题

### Q1: 录制的动作回放时位置不对？
确保录制和回放时屏幕分辨率一致，目标窗口位置相同。

### Q2: 快捷键不生效？
检查是否有其他软件占用了 F7-F12 快捷键。

### Q3: 脚本保存后找不到？
脚本默认保存在程序目录下的 `scripts/` 文件夹中。

### Q4: 回放时速度与录制不一致？
软件已优化时间精度，如仍有差异请检查是否有其他程序占用系统资源。

### Q5: 如何发布新版本？
```bash
git tag v1.x.x
git push origin v1.x.x
```
GitHub Actions 会自动构建并发布。
